ReviewPro Mockup Kit

A simplified HTML + CSS design system for building ReviewPro prototypes with AI. Describe a screen to Kiro, or drop in a screenshot, and get a fully interactive, self-contained HTML mockup. No build tools, no frameworks.

Download kit ZIP archive with the design system, templates, the Kiro skill and examples

Quick Start

1DownloadUnzip to any folder
2Open in KiroFile → Open Folder, then Trust
3DescribeTell Kiro what to build

The skill activates automatically. Describe any ReviewPro admin screen and Kiro generates interactive HTML you can open in a browser. On macOS nothing else is needed; Windows needs python on the PATH.

How to Use

You can work with Kiro in several ways:

  • Add a screenshot or a Figma frame: Kiro recreates it as interactive HTML
  • Describe the feature or interaction you want to prototype
  • Combine both: paste a screenshot and explain what should change

Kiro creates a self-contained folder in mockups/. Open any HTML file in a browser, click Edit (bottom left) to fine-tune it like in Figma, or import the folder into Figma Make as a code prototype.

For Maintainers

The kit is plain files: design-system/ is the source, templates/ holds the copies each mockup gets. Read the contributing steering file, run python3 .kiro/scripts/check-mockup.py --all before you share a change, and rebuild this website and the download with python3 .kiro/scripts/build-site.py.

There is no auto-update: to update, download the new zip and replace design-system/ and templates/. Your mockups/ folder stays as it is.

What Is This

A lightweight HTML + CSS design system that lives entirely in your project folder. You describe a ReviewPro screen to Kiro and it generates an interactive, self-contained prototype: no build tools, no frameworks, no npm.

What It Is

  • A simplified design system for rapid prototyping with AI
  • One CSS file (shared.css), the ReviewPro icons from Figma (rp-icons.css) and one JS file (shared.js)
  • Class names that match @reviewpro/ui-components: rp-main-button is <MainButton>
  • The new navigation: blue top bar, icon rail, section panel
  • Open the HTML in any browser: works offline, no server needed

What It Is Not

  • Not the production design system (@reviewpro/ui-components)
  • Not connected to Storybook, React or the real frontend
  • Not meant for production code: it is for UX exploration and quick validation

How It Works

Download the kit, open the folder in Kiro and describe what you want to prototype. Kiro picks the closest of ten page patterns, reads the component docs it needs, and builds pages from real components: tiles, tables, fields, menus, dialogs and drawers that already click, filter, sort, paginate and validate. A checker catches invented components, missing assets and dead buttons before you see the result.

Developers read a mockup as React: design-system/HANDOFF.md maps every class to its component and prop.

When to Use It

  • Exploring a new feature before committing to full design
  • Showing an idea to product managers, engineers or customers with a clickable prototype
  • Recreating a production screen from a screenshot to try a change on it
  • Creating a Figma code prototype from a conversation with AI
