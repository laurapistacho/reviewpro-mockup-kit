# Handoff: kit classes → @reviewpro/ui-components

Generated by `.kiro/scripts/build-docs.py` from `design-system/rp-map.json`. Do not edit.

Read a mockup as React: the root class is the component, every other class of the element is a prop.
No modifier class means the default prop. `kit-` classes are page layout (no component).

## Naming

- **root**: rp-{component} = the React component (kebab case of its name)
- **prop**: rp-{component}-{value} or rp-{component}-{prop}-{value} = one prop value; no class = the default value
- **boolean**: rp-{component}-{prop} = a boolean prop set to true (rp-main-button-danger = danger)
- **disabled**: the disabled attribute on a native control = disabled prop
- **kit**: kit-{name} = page layout of the kit, no React component (write it as layout in the page)
