# Icon Reference

Every ReviewPro icon (generated by `.kiro/scripts/build-icons.py`, do not edit). The drawing comes from the Figma icon
library (Pictograms and Icons) when Figma has it, otherwise from `@reviewpro/ui-components/icons`.
Use the **Class** column: `<span class="rp-icon rp-icon-search"></span>` is `<Search size={24} />`.
**Figma only** = no React icon yet: tell the developers, they need to add it to `@reviewpro/ui-components/icons`.
Sizes: no class = 24px (pass `size={24}` in code, the code default is 32), `rp-icon-size-12 | 16 | 20 | 32 | 48 | 80`.
Color: the icon takes the text color (`color` prop in code). Multicolor icons keep their colors.
