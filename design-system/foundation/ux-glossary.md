# UX Glossary

Content, wordings and common terms that you might find in our design system.

Use it to pick the verb of an action (buttons, menu items, links) and the word for a thing (Nouns, at the end). Case follows `rules.md` § Writing: buttons and menu items in sentence case, verb + noun (Show more, Translate all, Mass upload). New mockups and V2 copies use it. When recreating an existing screen, ask the designer first whether to keep the labels in the app or improve them.

## Actions

| Label | What it does | How to use it |
|-------|--------------|---------------|
| Actions | Shows the list of secondary actions related to the current object or page. | |
| Add | Takes an existing object and uses it in a new context (for example, adds an item to the cart, adds a user to a group, or adds a document to a folder). | Be careful between New and Add. Should be used followed up by a noun. |
| Apply | Saves changes without closing the dialog. These properties often affect subsequent system behaviour. | Use instead of Save changes. Save can be used instead of Apply as well. |
| Assign | Allocates a case, conversation or other information to the recipient or user. | Use Unassign for the contrary action. |
| Back | Returns the user to the previous step in a sequence of steps, such as in a wizard. | Use instead of Previous. |
| Cancel | Stops the current action and closes the dialog. | Warn the user of any possible negative consequences of stopping an action from progressing, such as data corruption. |
| Clear | Clears all the fields or selections. Also deletes the contents of objects such as a log or a filter. Typically the default selection or value is re-established for controls that always have a default selection or value. | Be careful between Reset and Clear. |
| Close | Closes the current page or window (for example, closing a secondary window containing online help). | Do not use Close alongside OK or Cancel actions. If possible, for actions use the close icon instead. |
| Collapse | Enables you to collapse an expanded object that contains another object or element. | Be careful between Hide and Collapse. |
| Copy | Creates new instances of the selected objects in a specific destination. | If possible, for actions use the Copy to Clipboard icon instead. |
| Create | Makes a new object from scratch. | If possible, use New instead of Create. |
| Delete | Destroys an existing object so that it no longer exists (for example, deletes a file from a directory or deletes a value from a table cell). | If possible, for actions use this label combined with the danger variation. |
| Display | Exists on the app. | Try to use Preview or Show instead. |
| Done | Indicates that the user has finished working in an environment (for example, editing templates) and wants to return to where he or she came from. | |
| Download | Transfers a file from a remote system to a local system. | |
| Edit | Allows data or values to be changed. | |
| Expand | Enables you to expand a collapsed object that contains another object or element. | Be careful between Show and Expand. |
| Export | Saves data in a different format external to the system. Typically opens a native secondary window for the user to specify the name, file type and location. | |
| Filter | Shortens a list to objects that match the filter criteria. | |
| Flag | Highlights an element to indicate that there's an issue or ongoing problem related to the object. | Use Unflag for the contrary action. |
| Forward | Sends and assigns a message or other information to the recipient or destination. | |
| Go to | Redirects towards a different page, modal or scenario. | Should be used followed up by a noun. |
| Hide | Removes an element that was previously shown (for example, enables the user to hide details or descriptions). | |
| Import | Transforms data or objects from an external source. Typically opens a secondary window for the user to locate the external source. | Do not use instead of Upload. |
| Log in | Enters a site or application. This choice typically opens a form for entry of credentials. Also used on the submission button after users enter their credentials. | Use instead of Sign in. This is to make it visually distinct from Sign up. |
| Log out | Exits an application or site. | Use instead of Sign out. |
| Manage | Controls or modifies the object or objects. For example, users, tags or categories can be managed. | Can be used followed up by a noun. |
| New | Starts the creation of a new object. New either creates the object immediately or opens a dialog or set of fields where the user can enter properties. | Combine New with a noun to specify the action. Use New instead of Create. |
| Next | Advances the user to the next step in a sequence of steps, such as in a wizard. | Can be substituted or followed by the Right Chevron arrow icon. |
| OK | Confirms an action or completes the current task. | Best practice is to use a label corresponding to the specific action. Use only as a last resort. |
| Preview | Shows how an object or content will appear with formatting applied before the content is published or distributed. Alternatively, provides an incomplete display of an existing object without leaving the current context. | Be careful between the terms Preview and Show. |
| Publish | Uploads an object or content to a third party url, website or product. | |
| Refine | Makes minor changes or funnels so as to improve or clarify the content of an object or information. | Careful with Reset, Clear and Refine. |
| Refresh | Reloads the view of an object when the displayed view has become unsynchronised with the source. | |
| Release | Removes or reverts the assigned user from the conversation, case or object. | |
| Remove | Removes an object from the current context but the object is not destroyed as a result of the action (for example, removes a user from a group or removes an item from the cart). | Can be combined with a noun. Be careful between the terms Remove and Delete. |
| Reply | Indicates or completes a response to an email or a comment. | |
| Reset | Reverts values back to their last saved state. The last saved state includes the values stored the last time the user clicked Apply. Does not close the dialog or window. | Be careful between the terms Reset and Delete. |
| Resolve | Changes the status of the object as resolved meaning that it is completed or closed. | |
| Save | Saves pending modifications made to a file or document. Does not close the window or panel. | |
| Save as | Creates a new object based on the state of the object currently being viewed. The user names the new object and typically identifies its location. | |
| Schedule | Programs an action, once or in multiple instances, for a determined time or moment in the future. | |
| Search | Returns all objects (for example, files, names, or documents) within a defined set (for example, in a folder, directory, database, or the internet) that match some specified criteria. | Used as a placeholder in most of the occasions. |
| Select | Selects data from an object. | |
| Select all | Adds all objects in the view to the selection set or checks all checkboxes. | |
| Send | Transfers an email, message or other information to the recipient or destination. | Can be used followed by a noun. |
| Show | Reveals an object that was previously hidden (for example, shows descriptions or shows further details). | Often used with a noun, for example Show more / Show less. Pair it with Hide for expand / collapse. |
| Sort | Sorts a list or table column. | |
| Sort by | Sorts a list or table column by the selected criteria. | |
| Start | Deploy an app or service to its development or production environment so that it can be used. | Use instead of Launch. |
| Tag | Adds a tag to the object. | |
| Translate | Expresses or converts the sense of words or text within an object into another language. | Can be used followed up by a noun, for example Translate all. |
| Undo | Reverts to the state before the most recent changes made by the user. Repeated use successively reverts to prior states in reverse chronological order. Applies to changes in data and not to changes made to the view. | Be careful with Clear and Reset. |
| Update | Label for a button in a dialog or form for editing an object. The settings in the dialog are applied to the object when it is updated. | Be careful with Save and Update. |
| Upload | Transfers a file from a local system to a remote system. | Can be used followed up by a noun, for example Mass upload. |
| View | Presents additional information or properties for the object. | Do not use instead of Show. |

## Nouns

One word per thing: use the word in the first column, never the ones in the second.

Draft, 18 Nov 2026: taken from the words the kit's starter pages use most. Check each row against the product before treating it as final.

| Use | Not | Meaning |
|-----|-----|---------|
| establishment | hotel, property | One hotel or venue in the account. "Hotel" and "property" stay inside names: Azure Bay Hotel, Property Management System |
| group | chain, portfolio | A set of establishments: Coastal Hotels Group |
| guest | customer, client | The person who stays, reviews or sends messages |
| review | comment, opinion | What a guest writes on a source |
| rating | score | What one review gives: 4.5 / 5 |
| score | rating | A metric: GRI™, NPS |
| reply | response, answer | What the establishment writes back to a review. "Response" stays in feature names: Response rate, Guest Responses |
| source | site, platform, OTA | Where reviews come from: Google, Booking.com |
| channel | | Where a notification or a message is delivered: email, web chat |
| conversation | chat, thread | All the messages with one guest; each one is a message. "Chat" stays in names: Web chat, Chatbot |
| case | ticket, issue | An item in Cases |
| survey | questionnaire, form | |
| alert | | A rule that tells users when reviews or scores need attention |
| notification | | What the user receives: in the bell or by email |
| user | member | A person with a Reviewpro login |
| competitor | compset | An establishment you compare against. "Competition average" keeps its name |
| department | category | Service, Cleanliness, Location, Value, Room, F&amp;B |
| settings | preferences | |
