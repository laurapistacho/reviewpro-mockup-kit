# ReviewPro UI App — Technical Context

Self-contained design system for building on-brand HTML mockups without dependencies. It mirrors `@reviewpro/ui-components` (the production React library) and the Figma UI App file (`ubE7R2jeqiwS8BZ4a5vwHw`) visually; it is not the production code.

## Composition model
| Layer | File | Role |
|-------|------|------|
| Runtime CSS | `foundation/shared.css` | Tokens, components, app shell, kit layout |
| Icons | `foundation/rp-icons.css` | Every production icon as a CSS mask (generated) |
| Runtime JS | `foundation/shared.js` | Selects, menus, overlays, snackbars, tabs, tables, validation, side bar |
| Visual editor | `foundation/tweak/` | Tweak mode (`#edit`), see `tweak/README.md` |
| Usage docs | `components/rp-*.md` | Markup, behaviour, rules; React line on top (generated) |
| Name map | `rp-map.json` | Every class → React component and prop. Source for the checker, the docs and HANDOFF |
| Handoff | `HANDOFF.md` | Read a mockup as React props (generated by `build-docs.py`) |
| Rules | `foundation/rules.md` | 26 absolute rules, sample data (The Metamorphosis), writing (with the Daylight kit's UX writing rules) |
| UX glossary | `foundation/ux-glossary.md` | The verb for each action (buttons, menu items) and the noun for each thing |
| Pattern matching | `foundation/decision-tree.md` | Request → starter → components |
| Blueprints | `pattern-blueprints.md` | Rules per starter |
| Starters | `examples/NN-*.html` | One working page per pattern (00–16), copied by `new-mockup` |
| Showcase | `examples/index.html` | Every component and variant |
| Icon catalogue | `foundation/icons-full-reference.md` | Every icon with its class and React import |

`templates/` holds byte-identical copies of the runtime files (the checker fails if they drift). Edit `foundation/`, then copy to `templates/`.

## Sources
| What | Where |
|------|-------|
| Components and props | `frontend-workspace/libs/ui-components/src/*` |
| Theme (palette, spacing, radius, shadows, z-index) | `frontend-workspace/libs/js-browser/src/themes/ui-app.ts` |
| Navigation (top bar, side bar, panel) | Behaviour and labels: `libs/reviewpro-ui/src/canvas` (MainBarNext, SidebarNav, ProductNavigatorNext, DateGroupComparison, AppLauncher). Sizes, colours and states: Figma UI App `ubE7R2jeqiwS8BZ4a5vwHw`, Navigation page 7144:36598 |
| Icons | Figma Pictograms and Icons (`sG8E7rdnYt59mgmYDMr7PY`, exported to `foundation/icons-figma/`), then `libs/ui-components/src/icons/*.tsx` for the rest (`build-icons.py`) |
| Figma-verified sizes (tables, buttons, fields, chips, switch) | `ai-tools-design-laura/mockup-kit` (pixel diffs against the Tables page) |
| Usage guidance | `ai-tools-design-laura/design-docs/` |

## Loading protocol (AI context)
The skill (`.kiro/skills/reviewpro-html-mockup/SKILL.md`) defines it: always `foundation/rules.md` + the matched pattern's blueprint; component docs only for components being added; the icon reference only for new icons.
